Quick help

What is a "slot" exactly?

Amazon gives every book 7 backend keyword fields, 50 characters each. Amazon indexes the words inside a field in any order, so a field holding murder mystery logic grid puzzles can match "logic grid murder" and "mystery grid puzzles" too. That's why packing beats picking single keywords.

Why does the tool delete words I added?

A word only counts once across your whole backend. If it already appears in an earlier slot, repeating it buys nothing and costs characters, so it's dropped from the packed string. The keyword chip stays so you can see what it contributed.

Why won't it let me write "Murdle"?

That's another publisher's brand. Using someone else's series name in your metadata is a fast way to get a book removed. The tool blocks it in slots and in generated text.

What if my key stops working?

You'll see a banner at the top. Email support for a fresh key. The keyword table, Slot Packer, character counters and checklist keep working without AI.

Can I use my own OpenAI key?

Yes. Click the badge in the top-right, choose Replace key, and paste any valid key.
