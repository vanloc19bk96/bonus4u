Quick Help

Why do I need to paste a key?

The tool uses AI to generate titles and descriptions for you. The key you were given lets that AI work inside this tool.

Is my key safe here?

Your key is stored only in your browser on this device, using the browser's built-in storage. It never leaves your device except to talk directly to the AI service. If you don't want it saved, uncheck "Remember this key on this device" during setup.

What if the key stops working?

You'll see a message at the top of the tool. Contact support and we'll send you an updated key. All the non-AI features (keyword picking, character counting) will still work in the meantime.

Can I use my own OpenAI key instead?

Yes. Click the AI badge in the top-right corner, choose Replace API key, and paste any valid OpenAI key. The tool works the same way.
